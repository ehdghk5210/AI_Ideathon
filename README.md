# 이런 경험 있으시죠? 

수백, 수천 장의 딥러닝 학습용 이미지... 일일이 마우스로 Bounding Box 치고 Polygon 외곽선 따느라 눈 빠질 것 같았던 적 있으신가요? 

작업자마다 숙련도가 달라서 라벨링 품질이 들쭉날쭉해 모델 성능까지 떨어질까 봐 걱정하신 적은요? 

연구할 시간도 부족한데 단순 반복 작업에 지친 분들을 위해 만들었습니다!

# 뭘 만들었나? 

*텍스트 프롬프트 기반 AI 영상 이미지 라벨링 보조도구를 소개합니다! 
*처음부터 직접 라벨링 필요 없이, AI가 초안을 잡고 사람은 검토/수정만 하는 방식으로 작업 패러다임을 바꿨습니다.

*✨ 단어만 치면 AI가 슥-삭: 찾고 싶은 객체 이름(예: pig, apple 등)을 텍스트로 치면, AI가 알아서 객체 위치와 영역을 자동 탐지합니다!
*🖱️ 마우스 딸깍 수정: AI가 잡은 영역을 드래그하거나 더블클릭해서 수정·추가하기만 하면 끝! 결과는 이미지 비율에 맞춘 JSON 파일로 즉시 저장됩니다!
*🔌 설치/인터넷 ❌, 오프라인 ⭕: 복잡한 파이썬, 라이브러리 환경 설정 필요 없습니다. 아나콘다 가상환경을 함께 패키징해서 .bat 파일 더블클릭 한 번이면 내 PC에서 바로 실행됩니다!

# 개선 효과는?

*⏱️ 작업 시간 약 80% 단축!: 1장당 평균 20분씩 걸리던 수작업이 단 2~5분으로 줄어듭니다! (이미지 내 돼지 12마리 기준)
*🎯 숙련도 상관없이 라벨링: AI가 동일한 기준으로 1차 영역을 잡아주기 때문에, 비숙련 담당자가 작업해도 향상된 품질의 데이터를 얻을 수 있습니다.
*🌐 무한한 확장성: 텍스트만 입력하면 돼지, 젖소는 물론 식물 데이터 등 모든 부서에 즉시 적용 가능합니다
*※ 단, 논문 구석에나 나올 법한 전공 단어나 '전설의 포켓몬' 같은 희귀 생물체를 입력하면... AI도 동공 지진을 일으킬 수 있으니 살살 다뤄주세요! 🤣

# 사용 방법(💻 Windows OS 전용)

*👉 다운로드 링크: https://github.com/ehdghk5210/AI_Ideathon
*📖 사용 설명서 확인: 링크 접속 후 메인 화면 아래에 있는 가이드 문서를 읽어주세요! 인공지능 모델인 sam3.pt 파일을 다운로드하는 방법이 적혀있습니다.
*📦 프로그램 다운로드: 화면 우측 중간에 있는 Releases 메뉴를 클릭하고 SAM3_LabelingTool.zip 파일을 다운로드하여 압축을 풀어줍니다.
*🏃‍♂️ 원클릭 실행: 준비해 둔 sam3.pt 모델을 폴더 안에 넣고 SAM3_LabelingTool.bat 파일을 더블클릭하면 툴이 즉시 실행됩니다.
